# A. Core D02 — Speaking Q1–2: Read a Text Aloud

## A1. Target

- 45 seconds preparation + 45 seconds response for each question.
- Finish within time without rushing the final sentence.
- Keep words recognizable; do not replace/add/remove word endings unnecessarily.
- Improve sentence stress, word stress, final sounds and chunking.
- Session target: **at least 2/3 for both Q1 and Q2**, with fewer word-identity errors than SW_S01.

## A2. 45-second preparation routine

Use this order every time:

1. Scan the whole passage once for meaning.
2. Identify punctuation and natural chunks.
3. Identify difficult multi-syllable words.
4. Check likely word stress mentally.
5. Plan emphasis on content words: nouns, main verbs, adjectives and key numbers/names.
6. Do not spend the full preparation time silently pronouncing every word from start to finish.

## A3. Reading rules

- Pause briefly at commas; pause more clearly at periods.
- Do not read every word with equal stress.
- Prioritize correct words over speed.
- If one word is mispronounced, continue; do not restart the sentence.
- Keep final `-s`, `-ed`, `-t`, `-d` sounds when they are part of the written word.

# B. Core D03 — Writing Q1–5: Picture Sentences

## B1. Target

- Complete all 5 questions within **8 minutes total**.
- Exactly one sentence per picture.
- Use both required words/phrases in every answer; changing word form is allowed when grammatically necessary.
- Session target: **11/15 or higher** and **zero omitted required keywords**.

## B2. Default sentence formulas

Prefer the shortest correct structure that fits the picture.

```text
A + person + is V-ing + object/location.
Several/Some + plural noun + are V-ing + ...
Many + plural noun + are + location/state.
A + person + wearing/holding/using + noun + is V-ing + ...
A + person + is V-ing ... while V-ing ...
There is/are + noun + location.
```

Default article rule:

- First mention of one non-specific person/object: `a/an`.
- Use `the` when the noun is already known or specifically identified, e.g. `the man on the left`.

# C. Bài bổ sung theo lỗi — tối đa 15–25% session

Only do this **after A and B are completed**.

## C1. Speaking repair

Select up to 8 words from today's audio that had one of these problems:

- wrong word stress;
- final sound omitted;
- word changed into another recognizable word;
- repeated hesitation.

Practice each word in this sequence:

```text
word → short phrase → full sentence
```

Do not replace the original first-take score with the repair recording.

## C2. Writing grammar survival check

Before submitting a repair sentence, check:

1. `a/an/the`
2. singular vs plural
3. `is/are`
4. `V-ing` after `is/are`
5. subject–verb agreement
6. preposition (`in/on/at/near/in front of`)
7. both required keywords present
8. sentence still matches only what is visible in the picture
