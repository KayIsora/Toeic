# A. Core D02 — Speaking Q1–2: Read a Text Aloud

## A1. Target

- 45 seconds preparation + 45 seconds response for each question.
- Finish within time without rushing the final sentence.
- Keep words recognizable; do not replace/add/remove word endings unnecessarily.
- Improve sentence stress, word stress, final sounds and chunking.
- Session target: **at least 2/3 for both Q1 and Q2**, with fewer word-identity errors than SW_S01.

## A2. 45-second preparation routine

Use this order every time:

1. Scan the whole passage once for meaning.
2. Identify punctuation and natural chunks.
3. Identify difficult multi-syllable words.
4. Check likely word stress mentally.
5. Plan emphasis on content words: nouns, main verbs, adjectives and key numbers/names.
6. Do not spend the full preparation time silently pronouncing every word from start to finish.

## A3. Reading rules

- Pause briefly at commas; pause more clearly at periods.
- Do not read every word with equal stress.
- Prioritize correct words over speed.
- If one word is mispronounced, continue; do not restart the sentence.
- Keep final `-s`, `-ed`, `-t`, `-d` sounds when they are part of the written word.

# B. Core D03 — Writing Q1–5: Picture Sentences

## B1. Target

- Complete all 5 questions within **8 minutes total**.
- Exactly one sentence per picture.
- Use both required words/phrases in every answer; changing word form is allowed when grammatically necessary.
- Session target: **11/15 or higher** and **zero omitted required keywords**.
- High-band practice target: the sentence should be **specific and informative**, not merely long. Add details only when they are visible or strongly supported by the picture and grammar remains controlled.

## B2. Controlled-detail strategy

Do **not** interpret `shortest sentence = best sentence`.

Use a three-level ladder:

### Level 1 — Core sentence

Use this only when vocabulary or grammar is uncertain.

```text
A + person + is V-ing + object/location.
Several/Some + plural noun + are V-ing + ...
Many + plural noun + are + location/state.
There is/are + noun + location.
```

Example:

```text
A man is decorating a cake.
```

### Level 2 — Core + one useful detail

Preferred default for practice.

```text
A + person + is V-ing + object + location/detail.
A + person + wearing/holding/using + noun + is V-ing + ...
```

Example:

```text
A man wearing an apron is decorating a cake with a pink tool.
```

### Level 3 — Controlled complex sentence

Use when a connector/keyword requires it or when grammar is secure.

```text
A + person + is V-ing ... while + S + is/are V-ing ...
Because + clause, + clause.
Clause + because + clause.
Now that + clause, + clause.
The audience is V-ing after + V-ing ...
```

Example:

```text
One man is looking at the engine while the other man is repairing the car.
```

**Rule:** detail is useful only if it improves relevance/specificity. Do not invent uncertain actions, causes or objects just to make the sentence longer.

## B3. Grammar rules to lock

### `man` vs `men`

```text
one man        = một người đàn ông
one of the men = một trong những người đàn ông
 two men       = hai người đàn ông
```

`man` is singular; `men` is the irregular plural.

With `one of the + plural noun`, the noun after `the` must be plural, but the grammatical subject is **one**, so the verb is singular:

```text
One of the men is repairing the car.
```

If exactly two men are shown:

```text
One man is repairing the car while the other man is standing nearby.
```

If several men remain:

```text
One man is working while the other men are watching.
```

### Quick survival checks

1. `a/an/the`
2. singular vs plural
3. `man → men`, `woman → women`, `child → children`, `person → people`
4. singular subject → `is`; plural subject → `are`
5. `V-ing` after `is/are` for visible ongoing actions
6. preposition (`in/on/at/near/in front of`)
7. both required keywords present
8. sentence still matches the picture
